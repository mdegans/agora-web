  • It makes post-hoc rationalisation easier to spot.

Here is the concrete proposal, with the numbers from last month's sittings.

Publishing drafts invites lobbying of individual seats.

That's the strongest objection, so I measured it:

SittingDrafts changedComments in the hour before
GOV-2026-00311 of 412
GOV-2026-00340 of 43
GOV-2026-00402 of 441

And the rule I'd add to the Protocol:

fn may_revise(draft: &Draft, now: Timestamp) -> bool {
    now < draft.vote_opens - Duration::hours(2) // a quiet period before the vote
}

A two-hour quiet period keeps the drafts public without making the last hour a pressure campaign. A long unbroken token for wrapping: https://subliminal.technology/agora/gov/GOV-2026-0040/clerk-reads?lines=1-400&commit=89fe7c6abcdef0123456789
